## Name

KeyHub — Local Passwords & Passkeys

## Short description

Local passwords, passkeys and autofill with your KeyHub desktop vault. Requires the KeyHub desktop app.

## Detailed description

KeyHub brings your local desktop vault to Chrome. Save and fill logins, use passkeys, and manage cards, identities and secure notes from the browser.

Requires the free KeyHub desktop application with Browser Bridge running. This extension is a companion to the desktop vault; it does not run a separate cloud vault or require a KeyHub account.

PASSWORDS WHERE YOU NEED THEM

Choose a matching login to fill its username and password. Save a website's login after reviewing the detected fields. Optionally enable save suggestions for sign-in, registration and password changes. Suggestions stay in temporary memory and require your confirmation before being saved.

PASSKEYS WITH CONFIRMATION

Create and use supported passkeys through a dedicated confirmation window. Private keys remain in the local desktop vault. Choose “Use device” to return to the browser's provider. Some websites and advanced WebAuthn options use the native browser flow.

YOUR VAULT IN THE BROWSER

Search and filter vault items; organize folders and favorites; manage cards, identities and secure notes. Fill supported card and identity forms on HTTPS websites. Deleted items go to trash, and previous passwords are available in encrypted history.

LOCAL CONNECTION, YOUR CHOICE

The extension communicates with KeyHub on your own computer. There are no ads or built-in analytics. Optional GitHub encrypted backup is configured separately in the desktop app. If you connect an AI agent through the desktop MCP service, it can request enabled credential actions, including filling a focused browser field and explicitly requested form submission.

GET STARTED

1. Download and run the compatible KeyHub desktop release.
2. Enable Browser Bridge and follow its pairing instructions.
3. Install this extension and pin it to the toolbar.
4. Open a website, unlock with your KeyHub PIN if configured, and choose an action.
5. Enable save suggestions only if you want the extension to detect submitted login information.

Desktop downloads: https://github.com/hhf666feng/KeyHub/releases/latest
Documentation and support: https://github.com/hhf666feng/KeyHub

LIMITATIONS

Browser management pages cannot be filled. Password, card and identity form workflows require HTTPS or local development pages. Custom forms, cross-origin payment frames, hardware attestation and advanced passkey features may require manual filling or the native provider. Normal popup autofill does not submit a form; agent-requested submission is a separate desktop-initiated action.
