# Environment Variable Group Editor

## Goal
Make multi-key environment configuration discoverable without changing the vault
schema or MCP secret model.

## Contract
- Add Environment variables as a first-class item template and keep the inline
  Environment variable group action in the existing credential editor.
- Parse one `KEY=VALUE` per line; support blank lines, full-line `#` comments,
  `export KEY=VALUE`, paired quotes, empty values and `=` inside values.
- Validate portable ENV names and reject malformed, duplicate, built-in-conflicting
  or already-present names atomically. Never add a partial paste.
- Generate ordinary hidden `customSecret` modules. Each generated field shows and
  permits editing its FIELD / ENV KEY before the credential is saved.
- Keep pasted secret values in the composer only until Add is chosen; never log,
  network-send or retrieve them. Clear the composer and remove pasted plaintext
  from the DOM when closing or switching away.
- Preserve existing custom-field, draft, Agent visibility, save, search and backup
  behavior. This does not import `.env` files or alter environment variables.

## Verification
1. Add synthetic regression scenarios in Chinese/English and desktop/narrow modes.
2. Confirm invalid and duplicate batches add zero fields and do not expose values.
3. Run localization, inline editor, editor layout, workspace and readability suites.
4. Build/package the macOS app, update it recoverably without changing vault data,
   then inspect the composer in the native unlocked UI without saving real secrets.

## Outcome
- The composer parses supported lines and generates ordinary hidden custom-secret
  modules. Malformed, duplicate or conflicting batches are rejected atomically.
- Tests: 4 env-group scenarios, 372 readability checks, 72 editor-layout checks,
  40 workspace cases, inline editor and owner-lock/quick-panel regressions pass.
- macOS release and portable checksums/signature verified. The new verified bundle
  is installed with a recoverable backup, while the already-running old GUI and 17
  active MCP processes were preserved to avoid discarding possible unsaved edits.
- A restart is required to load the new UI. Native interaction remains pending until
  the locked Mac is unlocked; synthetic screenshots are not a substitute.

- Added the Environment variables template to **Start with a combination**. It opens thesame batch composer directly and keeps Save disabled until added or cancelled.
- Native macOS verification passed on the installed build: the H template was visible,clicking it opened the composer, two synthetic keys were recognized and Add enabled,then the composer and editor were cancelled without creating a credential or draft.
