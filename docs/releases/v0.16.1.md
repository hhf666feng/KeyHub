# KeyHub 0.16.1

KeyHub 0.16.1 introduces safe credential preparation for agents and publishes the
current desktop, browser and headless builds under the KeyHub name.

## Highlights

- **Create without disclosing.** The new `items_create` MCP tool creates a named
  credential skeleton with empty hidden secret slots. Items such as an ASR API can
  be prepared with a public URL and blank API-key field, then completed locally in
  the KeyHub editor.
- **Fail-closed behavior.** A selected skeleton cannot silently fall back to another
  item's credentials. Duplicate names are rejected atomically, and creation errors
  do not echo rejected values.
- **KeyHub desktop experience.** The cross-platform workspace, compact menu-bar
  panel, bilingual UI, browser companion, vault management and encrypted GitHub
  snapshots remain available under the KeyHub name.
- **Documentation and demos.** English and Chinese READMEs now include recorded
  product walkthroughs, and portable packages carry their linked offline guides.

## Compatibility

Existing vaults, encryption keys, browser pairing, command aliases, template
aliases and backup formats remain compatible. New MCP tools require a new agent
session after installing this release.

## Downloads

Choose the asset matching the target platform. Verify the archive with
`SHA256SUMS.txt` before running it. **The macOS artifact in this release is
ad-hoc signed and not notarized because this repository has no Apple signing
secrets configured.** macOS may therefore require the standard Open action from
Finder; verify the downloaded checksum first. Future releases use Developer ID
signing and notarization automatically after the six Apple secrets are configured.
Windows uses the portable `.zip`; Linux provides a GUI AppImage archive and a
headless archive.
